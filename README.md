# деньги

Личный трекер платежей. В репозитории лежит только шифротекст: `index.html` — форма пароля и
AES-GCM-контейнер, ключ выводится из пароля (PBKDF2-SHA256, 250 000 итераций), расшифровка в браузере.
Данные живут в Supabase (`app_state`, строка `money`), ключи Supabase — внутри шифра.

Пересборка: `python3 build.py <пароль>` из папки с исходниками (`app-inner.html` + `build.py`).
